# 🧊 Cubo Finanzas — Análisis de Mercado Interactivo

Plataforma web interactiva creada para profundizar en el análisis de activos financieros, métricas de valuación y noticias macroe, complementando la publicación semanal de research en Substack.

🔗 **[Explorar Web Interactiva](https://francombina.github.io/Cubo-Finanzas/)**

## 🎯 Objetivo del Proyecto
Mostrar datos de mercado de manera visual e interactiva permitiendo analizar fundamentos corporativos y comparables de forma intuitiva.

## ⚙️ Características Principales
* **Herramientas de análisis fundamental y cuantitativo:** Visualización estructurada de métricas financieras y ratios de mercado.
* **Procesamiento de datos:** Estructuración y limpieza de series financieras para facilitar la comparación entre activos y sectores.
* **Ecosistema de contenido:** Integración conceptual con el newsletter de estrategia y análisis financiero *Cubo Finanzas*.

## 🛠️ Stack Técnico
* HTML5 / CSS3 / JavaScript
* Modelado y visualización de datos financieros
